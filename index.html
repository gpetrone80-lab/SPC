Login Accounts — Master Admin

Create a unique password for each instructor or student. Students sign in with their Candidate ID (e.g. C-101) + this password and can only see their own records. Instructors sign in with their Instructor ID (e.g. INST-07). Give the person their ID + temporary password once — they are the only copy.

Existing Accounts

Deactivate blocks sign-in immediately (records are kept). Remove deletes the login profile — the person's evaluation history stays in Reports.

Academy Data — Backup, Restore & Reset

End of academy: download a full backup, then reset the site so the next class starts clean. A backup holds every evaluation, archived day, and the full roster. Login passwords are never inside a backup — after a reset, create fresh logins for the new class in the form above.

Change password

The old password stops working immediately. The person's Login ID and all their evaluation records stay exactly the same. Give them the new password once — it is not stored anywhere you can look it up.

Reset the entire site?

This erases all evaluations, all archived days, the whole roster, and every student & instructor login. Only your Master Admin account stays. There is no undo.

Correct Student — move this record

Only the student's name, ID # and class change. Times, checklists, notes and the PASS/FAIL stay exactly as recorded — pass rates and reports recalculate from the record itself, so nothing is double-counted.
